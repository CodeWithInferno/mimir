# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. The full text at that address applies to this project as if it were reproduced here.

## In short

- Be respectful and considerate. Criticise the work, not the person.
- No harassment, no sexualised language or imagery, no personal or political attacks, no publishing of other
  people's private information.
- Assume good faith, and accept that maintainers may edit or remove contributions that break these rules.

## Scope

It applies in every project space (the repository, issues, pull requests, discussions) and wherever someone
represents the project in public.

publishing: an e-mail address that is read>**. Reports are handled in confidence. The maintainers follow the
enforcement guidelines of the Contributor Covenant 2.1 (correction, warning, temporary ban, permanent ban).
